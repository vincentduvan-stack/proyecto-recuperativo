# Recuperativo Web - EduTech Chile

Portal educativo y de gestión informativa desarrollado para la evaluación recuperativa del módulo de **Desarrollo de Aplicaciones Web** (4° Medio Programación).

## Estructura de Directorios
* `index.html`: Página principal con marcado semántico estructurado.
* `novedades.html`: Sección secundaria generada mediante automatización en Python.
* `styles.css/style.css`: Hoja de estilos externa que administra el diseño visual y responsivo.
* `scripts/generador.py`: Script ejecutable para el procesamiento dinámico de contenidos.
* `assets/`: Directorio destinado a recursos multimedia e imágenes.
* `TESTING.md`: Bitácora de validación, pruebas locales/remotas y control de incidencias.
